# SimilarWeb

SimilarWeb is a digital intelligence platform offering a REST API for accessing website traffic estimates, audience demographics, keyword analytics, competitive benchmarking, app intelligence data, and lead generation insights. The API provides real-time and historical data covering traffic sources, search behavior, technographics, e-commerce shopper intelligence, and firmographic company data.

## APIs

- **REST API** — Real-time access to digital intelligence data via individual HTTP endpoints. Covers website traffic, traffic sources, audience demographics, keyword intelligence, mobile app performance, technographics, shopper behavior, and company firmographics.
- **Batch API** — Asynchronous large-scale bulk data extraction supporting up to one million domains per job, with delivery to Amazon S3, Google Cloud Storage, and Snowflake.
